## PrivKey

Open-source infrastructure for Bitcoin, Lightning, and Nostr. FROST threshold
signing, self-custodial key management, and high-performance relays in Rust, Zig,
and C. MIT licensed and self-hostable.

**Keep**, self-custodial key management for Nostr and Bitcoin, so no single device
holds the whole key: [keep](https://github.com/privkeyio/keep) (Rust),
[keep-android](https://github.com/privkeyio/keep-android) (Kotlin),
[keep-esp32](https://github.com/privkeyio/keep-esp32) (C),
[keep-startos](https://github.com/Start9-Community/keep-startos) (TypeScript).

**Libraries**: [libnostr-c](https://github.com/privkeyio/libnostr-c),
[libnostr-z](https://github.com/privkeyio/libnostr-z).

**Tools**: [wisp](https://github.com/privkeyio/wisp) (Nostr relay),
[noz](https://github.com/privkeyio/noz) (Nostr CLI),
[taproot-assets-rest-gateway](https://github.com/privkeyio/taproot-assets-rest-gateway),
[bosun](https://github.com/privkeyio/bosun) (Bitcoin PR triage).

We upstream our fixes: Bitcoin Core, Bitcoin Knots, BDK, rust-miniscript, ZF
FROST, Lightning BOLTs, negentropy. Current list at
[privkey.io](https://privkey.io/#technology).
